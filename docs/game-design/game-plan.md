# 水豚巧克力工坊：相似形訂單對決

> **企劃版本：** 1.0（依訪談整理）  
> **目前階段：** 素材初選完成；MVP 首版已實作，接下來需要實際試玩並依課堂回饋調整。

## 一、企劃摘要

兩位國中生在同一台裝置上輪流經營巧克力工坊，各自解同一張訂單。玩家選擇長方形或三角形巧克力模板，依原圖尺寸和包裝指定邊長求出縮放比例，再算出所有對應邊長。可愛水豚店長介紹訂單、提供比例提示，最後和玩家一起查看兩人的算式與設計。

| 項目 | 規劃 |
|---|---|
| 暫定名稱 | 水豚巧克力工坊：相似形訂單對決 |
| 學習者 | 台灣國中八、九年級學生 |
| 教學情境 | 課堂上兩位學生共用一台裝置，由教師帶領與回顧 |
| 遊戲形式 | 瀏覽器遊戲；同一裝置輪流操作，不做跨裝置連線 |
| 單局時間 | 約五分鐘 |
| MVP 數學重點 | 相似形縮放、比例與對應邊長 |
| 核心競賽 | 比較首次完整提交的算式、倍率和邊長證據；三項表現相同可平手 |
| 美術方向 | 明亮可愛的巧克力工坊；優先尋找 Kenney 2D 素材，加入水豚店長 |

## 二、學習設計

### 可觀察的學習成果

給定一個巧克力圖樣的原始尺寸，以及包裝訂單指定的一組對應邊長，玩家能夠：

1. 找出原圖邊與目標邊的對應關係。
2. 用「目標邊長 ÷ 原圖對應邊長」求縮放比例 `k`。
3. 用同一個 `k` 計算圖樣上所有對應邊長，並提交比例算式和結果。
4. 說明所有對應邊使用同一比例時，圖樣才會保持相似。

遊戲把「算式方向正確」和「所有對應邊長正確」分開檢視，讓教師能看出玩家是理解比例關係，還是只猜中尺寸。MVP 訂單採用容易檢查的整數或簡單分數，避免繁瑣運算蓋過相似形概念。

### 課程銜接

教育部國教院數學領域課程手冊列有相似多邊形、對應角與對應邊比例，以及三角形相似等學習內容。企劃以九年級相似形內容作主要課程錨點；八年級先安排視覺化的等比例放大縮小作為前導，這是本遊戲的難度銜接設計，不代表手冊把該前導活動列為八年級標準。[數學領域課程手冊（113 年 3 月更新版）](https://www.naer.edu.tw/upload/1/16/doc/2021/%E6%95%B8%E5%AD%B8%E9%A0%98%E5%9F%9F%E8%AA%B2%E7%A8%8B%E6%89%8B%E5%86%8A%EF%BC%88113%E5%B9%B43%E6%9C%88%E6%9B%B4%E6%96%B0%E7%89%88%EF%BC%89.pdf)

### 數學規則

```text
縮放比例 k = 目標邊長 ÷ 原圖對應邊長
縮放後的每一邊 = 該邊原長 × k
```

長方形的長、寬都乘上同一個 `k`；三角形的三組對應邊也都乘上同一個 `k`。MVP 不提供可分別拉伸水平與垂直方向的自由變形工具，以免玩家改變形狀卻仍被判定為相似。

## 三、遊戲流程與核心玩法

### 五分鐘單局

| 目標時間 | 流程 |
|---|---|
| 0:00–0:30 | 水豚店長說明訂單與目標邊長，展示原圖尺寸 |
| 0:30–1:50 | 玩家一選模板、顏色或簡單裝飾，提交比例算式和對應邊長 |
| 1:50–2:00 | 遮住玩家一答案，顯示交接畫面 |
| 2:00–3:20 | 玩家二完成同一張訂單；玩家一的答案保持隱藏 |
| 3:20–4:20 | 一起揭曉兩份設計、算式、正確性與提示紀錄 |
| 4:20–5:00 | 水豚提出一個回顧問題，教師帶領簡短討論 |

這些時間是節奏目標，不設個人倒數或速度加分；玩家可以思考和使用提示。

### 玩家操作

1. 看訂單：確認原圖尺寸，以及包裝要求的目標邊長。
2. 選擇長方形或三角形模板，再選巧克力顏色或簡單裝飾。
3. 選出或填入比例算式，輸入 (k) 和模板上所有對應邊的縮放後長度。
4. 提交後檢查結果；答錯時讀取水豚的比例提示並修正，可再次提交。
5. 交接裝置給另一位玩家。兩人都完成後才看見彼此結果。
6. 比較解法並回答回顧問題，例如：「目標邊和原圖哪一邊對應？為什麼每一邊都要乘同一個比例？」

### 訂單與難度

同一場比賽使用同一張訂單主題。玩家可以各自選不同形狀，因此訂單資料要為兩種模板準備難度相當的數值：使用相同縮放比例、相近的數字複雜度，並以「比例算式正確、所有對應邊長正確」兩項共同標準判定，不按填寫欄位數量加分。

八年級前導關卡以圖像對應、整數倍率和直觀的放大縮小為主；進階關卡增加分數倍率、多邊形與三角形相似的邊長推理。長方形和三角形都可在 MVP 選擇；後續關卡再依答題表現解鎖更複雜的訂單。

## 四、回饋、競賽與評量

- **數學正確是必要條件：** 比例算式方向正確，且所有對應邊長正確，才算完成訂單。
- **錯誤可修正：** 不扣分、不取消進度。提示聚焦在「先找對應邊，再用目標 ÷ 原圖求同一個倍率」。
- **不靠速度分勝負：** 不使用個人倒數或快答加分；裝飾只用來表現創意，不影響 MVP 數學成績。
- **記錄但不懲罰：** 首次完整提交把比例算式、倍率、全部對應邊長分別記為一項數學證據；之後可看提示並修正，不扣分。提示使用和提交次數也會保留給師生回顧。
- **允許平手：** 兩人都正確就平手；若只有一人完成正確解法，該玩家勝出。最終畫面保留完整算式和各邊長，方便教師核對。
- **學習證據與遊戲參與分開：** 遊戲完成、解鎖或裝飾選擇代表參與；算式、對應邊長和口頭說明才是數學理解證據。

## 七、實作架構與步驟

### Phaser 架構

目前專案以 `GameScene` 作為遊戲直接入口。MVP 先在這個 Scene 內管理訂單、玩家一、交接、玩家二、揭曉與回顧等階段，不另做網站首頁。Scene 是 Phaser 中承載遊戲畫面和生命週期的一個場景單位；此案先用一個場景讓核心流程簡單可維護，未來流程變複雜再拆分。

建議程式責任：

- `GameScene`：流程狀態、玩家輪替、答案遮蔽和畫面切換。
- `src/game/data/learning/`：訂單、模板尺寸和難度資料。
- `src/game/systems/`：比例計算、尺寸判定、進度解鎖規則。
- `src/game/ui/`：訂單面板、輸入元件、提示、交接與結果畫面。
- `public/assets/`：已挑選並核對授權的 Kenney 與原創圖像。

### 實作順序

#### 第 0 步：完成素材挑選（已完成，先於 MVP）

1. 檢視 Kenney 預覽和候選素材包，確認圖像是否適合工坊畫面、巧克力模板與介面。
2. 到各素材包的官方頁面確認檔案內容、格式和授權；整理一份素材清單。
3. 決定水豚店長的來源。找不到合適素材時先完成原創水豚 2D 圖像與基本表情。
4. 固定 MVP 所需圖像、配色和字體，再放入專案素材目錄。

**完成條件：** MVP 所需圖像已選定、可用、授權已確認，水豚角色方向也已確定。首版使用的素材和檔案位置已記錄在[素材挑選紀錄](../assets/asset-selection.md)。

#### 第 1 步：製作 MVP（首版已實作，待試玩調整）

1. 由遊戲直接進入訂單，實作單一訂單主題與長方形／三角形兩種難度相當的資料版本。
2. 完成模板與顏色／簡單裝飾選擇、比例算式選擇或填寫，以及所有對應邊長輸入。
3. 實作一致倍率的計算與檢查；錯誤時給比例提示並允許修改。
4. 完成玩家一作答、遮蔽答案的交接畫面、玩家二作答，以及兩人完成後才揭曉。
5. 顯示雙方算式、尺寸、首次完整提交的三項數學證據、提示紀錄和修正次數；先比首次提交證據，三項皆相同則平手。
6. 加入水豚店長的訂單說明、提示和回顧對白。

**MVP 首版已涵蓋：** 兩人能在同一台裝置輪流解同一張訂單；各自答案在完成前互相不可見；兩種形狀都以同一個 `k` 縮放；提示與重試不扣分；結算展示可檢查的數學證據。接下來需在瀏覽器試玩，調整版面、輸入節奏與課堂使用細節。MVP 不納入面積效率、線上帳號、跨裝置連線或自由繪圖。

#### 第 2 步：迭代一——課堂節奏與難度進程

- 加入從簡單倍率到分數倍率、更多邊數和三角形相似推理的訂單。
- 依「最終能正確寫出比例並算對對應邊」解鎖下一難度；提示後修正仍能過關，首次正確和提示使用留作回顧資料。
- 調整每位玩家的輸入時間、交接遮蔽、文字大小和教師回顧問題，讓一局仍接近五分鐘。
- 核對形狀選擇不會造成題目難度或計分不公平。

**完成條件：** 初學者能從視覺化提示開始，答對後遇到較難訂單；教師能從畫面看到學生的算式與對應邊長，而不只看到勝負。

#### 第 3 步：迭代二——面積與包裝利用率

- 加入相似圖形面積與邊長倍率平方的關係：面積倍率為 `k^2`。
- 引入固定包裝規格，讓玩家比較包裝利用率或材料浪費。
- 為確保公平，直接競賽的雙方要使用相同形狀與包裝限制；若仍允許不同形狀，改比較各自相對於同類模板的利用率，不把形狀本身的面積優勢當成數學表現。

**完成條件：** 玩家能區分邊長按 (k) 改變、面積按 (k^2) 改變，並能根據明確的包裝限制解釋利用率。

#### 第 4 步：迭代三——內容擴充與重玩

- 加入更多顧客訂單、可收藏的包裝圖樣、更多形狀或裝飾。
- 依課堂回饋改善提示和題目變化；確保美術選擇仍不干擾尺寸標示與數學判斷。
- 若教師有需要，再規劃課堂紀錄或教師檢視功能；不預設蒐集學生個人資料。

## 八、企劃決策與待確認細節

下列核心方向已由訪談確定；題目數值、解鎖門檻和素材包則在實作前依所選素材與課堂節奏細化。

- 八、九年級；幾何與面積主題，以比例／相似形縮放作 MVP。
- 水豚店長加入巧克力工坊；美術明亮可愛，優先挑 Kenney 2D 素材。
- 兩位學生在課堂共用一台裝置輪流挑戰，一局約五分鐘；不需要網路對戰。
- 兩人解同一張訂單，各自選長方形或三角形，答案在雙方完成前隱藏。
- 先選或填比例算式，再輸入所有對應邊長；錯誤可看提示重試，不扣分。
- MVP 比正確算式和正確尺寸，答對者勝；都答對可平手；面積效率留到後續。
