# 學習與遊戲設計

本遊戲的學習設計與實作計畫詳見[遊戲企劃書](../game-design/game-plan.md)。

## 學習者與情境

- 對象／年級：台灣國中八、九年級學生
- 已有知識：從等比例放大縮小的直觀經驗，逐步進入相似形比例與三角形相似
- 使用情境與時間：課堂兩位學生共用一台裝置，約五分鐘一局，由教師帶領回顧

## 可觀察的學習成果

- 學習者能做什麼：由原圖尺寸和目標對應邊求縮放比例，並計算全部對應邊長
- 在什麼條件下完成：處理長方形或三角形巧克力圖樣的包裝訂單
- 用什麼證據判斷：比例算式、縮放比例、所有對應邊長，以及玩家對「同一比例保持相似」的說明

## 核心玩法與回饋

- 玩家行動：選模板與裝飾，提交比例算式和縮放後的對應邊長
- 遊戲規則與狀態變化：兩位玩家輪流解同一訂單，彼此答案在雙方完成前隱藏
- 結果如何呈現、如何重試：揭示算式與尺寸；錯誤時給比例提示，可修正重試且不扣分

## 評量與延伸

- 遊戲內可觀察的證據：比例方向、倍率和全部對應邊長；另列首次作答與提示使用紀錄
- 遊戲外的反思或新情境任務：教師引導學生解釋相似理由；後續加入面積倍率 `k^2` 與包裝利用率
